# iitsGuru

Personal site for [iitsGuru](https://x.com/iitsGuru) — a glitch/CRT landing, an on-chain art gallery powered by a Sovereign auction house contract, and a community-builds showcase.

## Stack

- Next.js 15 (App Router) + React 19
- Tailwind CSS v4 (`@theme` design tokens; dark-only)
- wagmi + viem + RainbowKit for wallet/contract reads & writes
- @tanstack/react-query for client cache
- Reads auctions directly from `SovereignAuctionHouseFactory` on mainnet — no backend, no indexer

## Routes

| Path | Purpose |
|------|---------|
| `/` | Glitch landing with nav |
| `/art` | Artist hero + live + past auctions (server-rendered, revalidate 60s) |
| `/art/[auctionId]` | Auction detail: sticky media + bid form / settled summary, provenance, contract refs |
| `/community` | Hand-curated community-builds tile grid |
| `/sitemap.xml`, `/robots.txt`, `/icon` | Generated by Next |

## Setup

```bash
npm install
cp .env.example .env.local   # edit values
npm run dev
```

## Env vars

Only `NEXT_PUBLIC_ARTIST_ADDRESS` is required. Everything else has an ENS-or-default fallback. See [.env.example](./.env.example) for the full list.

Recommended: set `NEXT_PUBLIC_RPC_URL` to your own Alchemy/Infura endpoint — page loads get noticeably faster than the bundled public-RPC fallback chain.

For mobile-wallet (WalletConnect QR) support, set `NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID` (free, ~2 min at [cloud.reown.com](https://cloud.reown.com)). Without it, the connect modal still surfaces every browser-extension wallet (MetaMask, Rabby, Coinbase Wallet, Safe, etc.).

## Aesthetic vs. data

Visual layer (CRT scanlines, glitch text, custom canvas cursor, warped grid background) is the iitsGuru identity and lives in `app/globals.css` + `app/components/CustomCursor.tsx` + `app/components/GlitchGrid.tsx`. All three respect `prefers-reduced-motion` and the cursor is disabled on touch / coarse-pointer devices.

Auction data layer is ported from [sovereign-artist-site](https://github.com/iitsGuwu/sovereign-artist-site) — `lib/` and `components/` mirror that repo's contract reading, ENS resolution, IPFS gateway racing, and bid/settle flow.

## Deploy

Netlify config is in [netlify.toml](./netlify.toml). Vercel works out of the box (`vercel.json` is shipped). Both will prompt for `NEXT_PUBLIC_ARTIST_ADDRESS` on first deploy.
