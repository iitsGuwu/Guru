# iits.Guru

A minimal, intricate bento box style portfolio site with an animated starry sky background.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- **Bento Box Layout**: Modern grid-based design with responsive sections
- **Animated Starry Sky**: Beautiful animated background with twinkling stars
- **Interactive Ideas Section**: Hover over project ideas to see detailed descriptions
- **Responsive Design**: Optimized for all screen sizes from mobile to desktop
- **Smooth Animations**: Elegant transitions and hover effects
- **Touch Optimized**: Mobile-friendly interactions with tap support

## Project Structure

- `app/page.tsx` - Main page component with bento box layout
- `app/layout.tsx` - Root layout with background animation
- `app/globals.css` - Global styles and animations
- `public/assets/` - Static assets (images, logos)

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
